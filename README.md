# AIWorld

**本地运行的 AI 文字世界引擎。** 你打字，模型接着往下写——而且它记得住时间、地点、谁在场、谁身上有什么变化。

它不是一个聊天框里跟你对话的 AI，是一台**替你跑世界的机器**：你输入"推门进去"，它写出推门之后发生的事；你输入"第二天早上我去学校"，它把时钟推过去；戏里的人有各自的资料、状态和知情范围，不会知道不该知道的事。

数据全在你自己的机器上（`content/<世界>/`），模型可以走本地 Ollama，也可以走任意 OpenAI 兼容的付费网关。

## 一、把它跑起来

### 方式 A：手上有一份「AIWorld-一键包」

包里自带 Python 运行环境，**不需要装任何东西**。

1. 整个文件夹拷到电脑上任意位置（如果拿到的是 zip，先解压）。
   ⚠️ 别用资源管理器的「全部解压缩」——它偶尔会**静默漏掉文件**，解压出来就是个跑不起来的包。用 7-Zip，或直接拖文件夹。
2. 双击 **`run.bat`**。（双击 `run.py` 也行 —— 它会自己换成包内自带的运行环境；`run.bat` 的好处是出错时窗口不会关。）
3. 第一次会停下来说没填 API key —— 用记事本打开目录里的 **`.env`**，找到这一行填上你的 key，保存：

   ```
   AIWORLD_LLM_API_KEY=sk-你的密钥
   ```

   💡 包里默认已经配好 DeepSeek（`AIWORLD_LLM_BASE_URL=https://api.deepseek.com`）。**用的不是这家**，就顺手把 base_url、`AIWORLD_MODEL_MAIN`、`AIWORLD_MODEL_CHEAP` 一起改成你家的（见第二节）。
4. 再双击 `run.bat`。看到 `URL : http://127.0.0.1:8765/` 就成了 —— 那几行里还有两行是用来**认领自己**的：**`Build`**（这个包是什么时候、从哪个提交打的）和 **`Folder`**（你启动的到底是哪个目录）。手里同时有几份包时，靠它们就不会搞混。
5. 在浏览器里打开 **<http://127.0.0.1:8765/>**（服务不会自己弹浏览器）。
6. 玩完了：在那个黑窗口里按 `Ctrl+C`，或直接关掉窗口。

> 💡 **不想花钱**：本地跑 Ollama / LM Studio 也行。key 随便填一串非空的（比如 `ollama`）——它不能留空，留空服务会直接拒绝启动。

### 方式 B：从仓库跑

需要自己装 Python **3.11 或更高**。在仓库目录里：

```bash
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -e .        # Windows
# .venv/bin/python -m pip install -e .                # macOS / Linux
```

然后双击 `run.bat`（或 `.venv\Scripts\python.exe app\main.py`），同样打开 <http://127.0.0.1:8765/>。

⚠️ **仓库里没有 `content/`**（世界与存档属于运行数据，不进版本库），所以第一次启动时世界列表是空的 —— 先去第四节弄一个世界进来。

## 二、配模型（唯一必须配的东西）

只要对方提供 **OpenAI 兼容接口**就能用：Ollama、LM Studio、DeepSeek、通义、vLLM、各类中转站都行。

### 两个接口，各管一半的活

| | 干什么 | 特点 |
|---|---|---|
| **主模型** | 写正文（编剧）、跟你讨论（导演）、演 NPC（Actor） | 需要文笔好，是花钱的大头 |
| **辅助模型** | 质检、审计（时间/状态/场景登记）、分类、转正草稿 | 干的是"读一遍挑毛病"，便宜的快模型就够 |

**最省钱的配法**：主模型走付费 API，辅助模型走本地 Ollama。辅助那套留空 = 完全跟随主模型。

### 改法一：改 `.env`（保存后要重启服务）

```bash
AIWORLD_LLM_BASE_URL=https://api.deepseek.com
AIWORLD_LLM_API_KEY=sk-...
AIWORLD_MODEL_MAIN=deepseek-chat
AIWORLD_MODEL_CHEAP=deepseek-chat

# 可选：给辅助模型单独的出口（留空 = 跟随上面那套）
# AIWORLD_CHEAP_BASE_URL=http://127.0.0.1:11434/v1
# AIWORLD_CHEAP_API_KEY=ollama
```

本地 Ollama 的最小示例：

```bash
AIWORLD_LLM_BASE_URL=http://127.0.0.1:11434/v1
AIWORLD_LLM_API_KEY=ollama
AIWORLD_MODEL_MAIN=qwen2.5:7b
AIWORLD_MODEL_CHEAP=qwen2.5:7b
```

### 改法二：界面「设置」

顶栏 **设置** 里有同样的字段（主/辅助两套地址、密钥、模型名），保存后**不用重启**，写进 `data/settings.json`。

同一个面板里还有：

- **推理等级** —— `自动 / 低 / 高 / 最高`。写戏想要细节就调高（更慢更贵）。
- **注入上限** —— 编剧一次能看到多少条历史、NPC 记得多少事。**调大 = NPC 记性好但更贵**；填 `0` = 不限制，用于"NPC 老是忘事"的场合。
- **质检开关** —— 关掉后编剧的初稿直接进候选，更快，但没人替你挑毛病了。
- **字体大小 / 主题**。
- **Token 统计** —— 随时看自己烧了多少。

## 三、开一局，怎么玩

界面分三块：**左栏**（场景导航 / 在场 / 待转正 / 剧情目标）、**中间**（正文 + 输入框）、**右边抽屉**（导演 / 状态 / 转正 / 预设 / 设置）。

### 一次回合的完整流程

1. 在底部输入框打字，回车。输入可以是任何东西——**行动、对白、想法，甚至只是"我等着"**。
2. 上方出现状态行（`编排成文中` / `NPC Agent 思考中` / `质检员审校中` 之类），等它跑完。
3. 出来一稿正文。下面是一排控件：

   | 控件 | 作用 |
   |---|---|
   | **◀ ▶** | 在已经抽出来的几稿之间切换 |
   | **重抽** | 对同一个输入再写一稿，**追加到本回合**（可以连着抽几次，再用 ◀ ▶ 比较） |
   | **采纳** | 就用当前显示的这稿，落进故事正史 |
   | **放弃** | 整个回合作废，重新输入 |

4. ⚠️ **采纳是静默的**：本回合只有一稿时，你**直接接着打字**就等于采纳它。
   但如果你抽了好几稿，引擎会**拦住你**、要你先选一份或放弃这一回合 —— 它不会替你猜。所以挑到满意的那稿再往下走。

> 💡 想给这一回合额外加要求（"加强动作描写""写得慢一点"），用双括号写在输入里：
> `推门进去 ((多一点环境描写))`

### 时间怎么走

时间由引擎结算，**你不需要特殊语法**——想要它走多远，就在输入里把时间说清楚：

- `我在屋里坐到天黑，然后出门去码头。` → 引擎按这场戏的实际时长往前推
- `等到晚上八点，我去敲王蓉家的门。` → 直接定到八点
- 原地闲聊、什么也没发生 → 时间基本不动

顶栏的时钟鼠标悬停能看到上一次是怎么算的。

### 几个随时能点开的东西

- **顶栏「场景」** —— 场景卡：这地方长什么样、此刻有谁在、最近去过哪。点卡里的图看大图（`Esc` 关）。
- **顶栏「状态 N」** —— 当前角色状态，以及**这一回合新增/失效了哪些**。加错了可以在这里撤掉。
- **导演窗口** —— 戏外跟它商量：要建议、问设定、**设剧情目标**（大=主线，小=支线）、或者下幕后操作（覆写去向、注入记忆、改判），幕后操作会弹确认。
- **预设** —— 三条写作准则，见下。

### 编剧准则（预设）

| 字段 | 作用 |
|---|---|
| **创作与写作要求** | 排戏走向 + 正文风格合一。"不要主动揭穿秘密""克制写实，白描为主"这类都写这里 |
| **文风示范** | 粘一段你想要的笔法的文字（100~200 字）。模型只学**句子节奏和描写笔法**，示范的内容本身不会进正文——所以**建议选跟本世界题材距离远的文本** |
| **禁用词** | 逗号分隔。质检会硬拦替换掉（比如 `一丝, 不易察觉`） |

> 这几条**同时**喂给写正文的编剧和挑毛病的质检，所以质检会照着它主动改写 —— 想让模型"少打字、按你说的写"，放这里是杠杆最大的地方。

## 四、世界从哪来，怎么管

一个世界就是一个文件夹 `content/<世界id>/`。**一个世界目录同时就是一份存档**（进度也在里面）。

### 拿到世界的四条路

1. **新建** —— 顶栏「**世界工作台**」→ 面板顶部「**新建世界**」。展开后两条路：填一句话让 AI 起草，或者直接建一个空白世界。
2. **让模型起草** —— 给它一句话前提（"九十年代县城高中暑假，我和同桌在镇上晃荡"），它铺出世界概要、开局、几个场景、几个人物和几条世界书。**草稿先给你看，你改过、点确认才落盘。**
3. **导入** —— 世界工作台顶部「**导入为新世界**」选一个 zip（别人导出的资产包）；或者把别人给的整个 `content/<世界id>/` 目录拷进来。
4. **接着玩** —— 世界列表里点「**打开**」。一个世界就是一份存档，进得去就是接着上次。

### 世界工作台（顶栏按钮）

平时**随时可以改**，改完点保存即时生效，不用重启：

| 页签 | 改什么 |
|---|---|
| **概览** | 世界名、开局场景、世界概要（每轮都发给编剧的硬规则与基调） |
| **世界书** | 详细设定的条目。三条触发方式见下 |
| **场景** | 地点。可感知描述、别名、**消息域** |
| **人物** | 人物卡：外貌、人格、幕后注、听域 |
| **事件日志** | 已经发生的一切（正史，不可改） |

**切换世界 ▾** 和 **刷新** 在面板右上角；**新建世界** / **导入为新世界** 在面板顶部；底部是备份与复制：

| 按钮 | 作用 |
|---|---|
| 导出资产包 | 只有世界设定、**不含进度**，适合分享给别人 |
| 复制为新世界 | 连设定带进度复制成另一份，用来试分支 |
| 导出完整备份 | 设定 + 存档全量备份 |
| 导入备份 | 恢复一份完整备份 |
| 重置剧情 | 见本节末尾 |

### 世界书条目的三种触发方式（这是最容易搞错的地方）

| 方式 | 什么时候进提示词 |
|---|---|
| **关键词** | 玩家输入或已采纳的正文里**出现关键词**时（子串匹配，"王蓉"不会命中"阿蓉"）|
| **归属角色** | 那个角色**在场**时（不看有没有点名）|
| **常驻** | **每一轮都发**。没有条数限制 |

> ⚠️ 想让"提到 A 就顺便带出 B 的资料"（比如 A 的条目里写了"她父亲是 B"），**给 B 那条的关键词里加上「A」**。归属是绑**人名**的——挂了谁，就只在**谁**出场时生效，不会跟着别人一起进来。
> ⚠️ 归属条目**每人最多 2 条**，超了世界体检会标黄。
> ⚠️ 归属那一栏里有个 **「（无 · 纯关键词触发）」** 选项 —— 选它就等于**这条不归属任何人**，只能靠关键词或常驻进来。**想让它跟着主角走，就得在下拉里选主角的名字**；留空不会自动挂到主角身上。

### 场景的「消息域」怎么填

| 填什么 | 意思 |
|---|---|
| **留空** | **不传播** —— 这个地方发生的公开事件，谁都不会风闻（默认值）|
| **`全域`** | 全域公共 —— 人人都能听说 |
| **地域名**（如 `青石镇`）| 只有听域覆盖到那里的 NPC 才风闻 |

> ⚠️ 场景和人物的地域名**一定要用下拉选，别手打**。错一个字（"青石镇" vs "清石镇"）**不会报错**，后果是那个人从此静默地收不到消息，事后极难归因。

### 重置剧情

世界工作台底部 → **重置剧情**。它清掉进度（事件、候选、状态、目标、未落卡名单、地点候选册），**工作台里你改过的世界设定一概不动**，然后从开局白重新开始。

⚠️ **一旦开局，主角就锁定了** —— 想换成别人当主角，必须先「重置剧情」，换完再开演。

## 五、玩着玩着会遇到的两件事：转正

引擎自己**不会**偷偷给你的世界添人物和场景，它只会把"候选"摆出来等你拍板。左栏出现 **「待转正 · N」** 时，去右边抽屉的 **「转正」** 页处理（每行默认收起，点开才展开）。

- **人物**：一个只有名字、跟你打过两轮以上交道的人，会在这里等你补一张正式人物卡。可以点一下向模型要一份 **「AI 草稿」**——注意它**只从这个人自己的已采纳正文里总结**，没写到的地方就留空（留空 = 还没写到，不是"没有"），所以务必自己核一遍。转正之后他就有了正式档案，再出场时引擎按这张卡演。
- **场景**：一个你反复去、或者打算再去的地方。
  ⚠️ **转正不会改变消息传播规则**。转正后想让这个地方的消息传出去，还得去世界工作台给它填**消息域**（见上一节）。
- 两边的 **×** 语义不一样：人物的 × 是"退回即兴角色"（出场计数清零）；场景的 × 是"定为临时"，从此不再打扰你。

## 六、用手机 / 平板玩（同一个 WiFi）

1. 改 `.env`：

   ```bash
   AIWORLD_HOST=0.0.0.0
   AIWORLD_AUTH_TOKEN=一串你自己编的长随机串
   ```

2. 重启服务。这时启动窗口会打印一个局域网地址（`http://192.168.x.x:8765/`）。
3. **Windows 防火墙**要放行入站 TCP 8765（首次运行可能会弹窗问，选"允许"；没弹就手动加规则）。
4. 手机上打开 `http://192.168.x.x:8765/?token=你编的那串` —— **带一次令牌就行**，之后这台设备会记住。

> ⚠️ 令牌走的是**明文 HTTP**，只在可信的家庭 / 办公室 WiFi 里这么用。要跨公网请自己套一层 HTTPS。
> 本机（127.0.0.1）访问**永远不需要令牌**，单人自己玩不用管这一节。

## 七、遇到问题先看这里

| 现象 | 原因 / 怎么办 |
|---|---|
| 双击 `run.bat` 窗口一闪而过 | 缺运行环境。方式 A 的包不该出现；方式 B 说明 `.venv` 没建好，按第一节重做 |
| 停在那儿说 `API key : MISSING` | 正常提示。按它说的填 `.env` 里的 `AIWORLD_LLM_API_KEY`，保存再跑 |
| 换了新包，看到的还是旧版本 | 先分两步认：① 看窗口里的 **`Build` / `Folder`** 两行 —— 确认你启动的是哪一份、在哪个目录；② 看世界工作台标题旁的 **`前端 v…`**（新旧代码的号不一样）。认下来之后按这两种原因查：**旧的那份服务还占着 8765**（新包会直接告诉你 `Port … ALREADY TAKEN`，并说明你看的页面是那一份）；或**浏览器把旧页面存住了**（最常见）—— 按一次 `Ctrl+F5` 强制刷新就好。从这版起已经改掉：入口页每次都重新取，不会再被存住 |
| 报 `No module named '…'`（最常见是 `uvicorn`） | 启动器现在会自己说清属于哪种：提示 `not the bundled interpreter` = 用的不是包内运行环境（改成双击 `run.bat`）；提示 `bundled runtime looks incomplete` 或 `package looks damaged` = 包没拷全，重新拷一遍 |
| 报 `Missing credentials` / `401` | key 没填、填错、或者 base_url 和 key 不是同一家的 |
| 世界列表是空的 | 还没有世界。去第四节新建 / 导入 / 拷贝一个 |
| 模型一直报错、超时 | 网关地址或模型名不对。先在「设置 → 主模型接口」里换成你确定能通的组合 |
| 手机连不上 | 三个都查：`.env` 里 `HOST=0.0.0.0` 了吗 / 防火墙放行 8765 了吗 / 用**带 `?token=` 的完整地址**了吗 |
| 手机上场景图、人物图不显示 | 多半是令牌问题（图也要鉴权）。重新用带 `?token=` 的地址打开一次 |
| 某个 NPC 怎么都不知情 | 查他的**听域**和场景的**消息域**，多半是地名打错了——下拉选，别手打 |
| NPC 老忘事 | 设置里把「注入上限」调大（或填 0）|
| 改了 `.env` 没反应 | `.env` 要**重启服务**；界面「设置」里的改动不用重启 |
| 改了世界设定没生效 | 工作台里没点「保存」；或者页面是旧的，`Ctrl+F5` 强刷一次 |
| 候选稿放太久没了 | 未处理的候选 **7 天后自动清理** |
| 状态栏显示"另有 N 条状态未列出" | 说明到了上限（主角 6 条 / 每个 NPC 3 条），重要的往上放 |

## 八、想改代码 / 看设计

- `docs/` 里有完整设计文档：**GDD**（策划）、**REQ**（机制需求清单）、**TDD**（技术设计），以及若干 `方案-*.md`。
- 目录速查：`app/` 后端 · `web/dist/` 前端（原生 HTML/JS，无构建步骤）· `content/` 世界与存档 · `data/` 设置与预设 · `tests/` 测试。
- 测试与静态检查：`./.venv/Scripts/python.exe -m pytest -q`、`./.venv/Scripts/python.exe -m ruff check`、前端 `cd web && node --test`。
- ⚠️ 改了 `web/dist/` 下的前端资源，要跑一次 `scripts/bump_frontend_version.py`（页面上 `?v=` 是**文件内容哈希**，所以带 `?v=` 的资源才敢长期缓存）。`index.html` 相反：一律 `Cache-Control: no-store` —— 它钉着 `?v=`，旧一份 = 整个前端锁死在旧版。口径在 `app/main.py` 的 `_StaticAssets`，测试在 `tests/test_main.py`。
